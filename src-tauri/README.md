# src-tauri — DEPRECATED

The Tauri 2 desktop shell. Deprecated as of 0.3.52: it is no longer a member of the Cargo
workspace, so it is not built, linted or released. The last release that carried desktop builds
(Windows portable zip and installer, macOS `.dmg`, Linux `.AppImage`/`.deb`/`.rpm`) is
[0.3.51](https://github.com/karthick-dkk/elasticpro/releases/tag/v0.3.51).

Only the hosted Docker build and the Zabbix modules are maintained. The folder stays in the tree
for reference; to rebuild the shell, check out the `v0.3.51` tag.
